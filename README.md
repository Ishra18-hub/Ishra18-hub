## 🎓 Final Year Design Project (FYDP)

**Solar Powered Water Desalination Using Evaporation Technique**

- Conducted extensive **literature review** on solar desalination technologies (MSF, MED, RO, solar stills)
- Contributed to the **system design** of a solar-powered desalination system using parabolic solar collector, spray-assisted evaporation, and fan-driven condensation
- Performed **technical analysis** and **report writing**
- Created **presentation slides** and delivered final presentation
- Analyzed CFD simulation results (ANSYS Fluent) for heat transfer and evaporation performance
- Documented system architecture, working principles, and performance metrics
- Achieved **32.35% thermal efficiency** (as reported by simulation team)
